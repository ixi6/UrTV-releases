# تلفزيونك الخاص · ixi6

تطبيقان مستقلان للشاشة الرئيسية وشاشة التوقف على Android TV وGoogle TV، لأندرويد 8 فأحدث.

- [الإصدار المستقر 4.4 — البناء 12](https://github.com/ixi6/UrTV-releases/releases/tag/apk-latest).
- [الإصدار التجريبي 4.4 — البناء 12](https://github.com/ixi6/UrTV-releases/releases/tag/apk-next).

يتضمن 4.4 صفحة تحديث جديدة بنسبة تنزيل فعلية، وبطاقات «ما الجديد؟» بحسب تغييرات الإصدار، وإعادة المحاولة، وإطار تركيز خفيف حول التطبيق.

التحديث من التلفزيون: إعدادات التطبيق ← الجوال والتحديث ← تحديث تلفزيوني ← تحقق من التحديث. قناة التحديث العادية تستخدم الإصدار المستقر؛ النسخة التجريبية للاختبار. يؤكد المستخدم التثبيت في نافذة أندرويد.

مكتبة الخلفيات: مركز التحكم ← مكتبة الخلفيات. اختر خلفية لتظهر علامة الاختيار، ثم اضغط تطبيق الخلفية المختارة. تتوفر إعادة التسمية والحذف؛ إزالة خلفية مدمجة من القائمة قابلة للاستعادة، وحذف المستوردة يزيل نسخة التطبيق دون المساس بالملف الأصلي.

المصدر خاص. هذا المستودع لتوزيع ملفات APK الموقّعة وإرشادات استخدامها فقط. تتوفر بصمات الملفات وإشعارات تراخيص المكونات مع كل إصدار. يُحافظ على التوقيع ومعرّفات التطبيق لاستمرار التحديثات والإعدادات.
