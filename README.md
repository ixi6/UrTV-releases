# تلفزيونك الخاص — التنزيلات

مستودع تنزيلات APK للإصدار المستقل من UrTV. ملفات المصدر محفوظة في مستودع خاص.

## التثبيت الأول

لأجهزة Android TV وGoogle TV بنظام Android 8 أو أحدث؛ يختلف التوافق بحسب الجهاز.

نزّل الملفين من [آخر إصدار مستقر](https://github.com/ixi6/UrTV-releases/releases/tag/apk-latest)، وثبّت شاشة التوقف أولًا ثم الواجهة:

- `urtv-screensaver.apk`
- `urtv-home.apk`

اسم الواجهة: **تلفزيونك الخاص**. تعمل هذه النسخة بجانب النسخة الأصلية، وقد تحتاج اختيارها من إعدادات الشاشة بعد تثبيتها.

## التحديث من التلفزيون

افتح إعدادات التطبيق ← الجوال والتحديث ← تحديث تلفزيوني، ثم أكمل موافقة التثبيت التي يعرضها Android. لا يحتاج التلفزيون حساب GitHub.

التحديث يحافظ على بيانات النسخة نفسها؛ لا تحذف التطبيق قبل التحديث. لا يصبح تعديل المصدر تحديثًا للمستخدمين حتى يُبنى ويُختبر ويُنشر إصدار APK جديد.

## الخلفية المتحركة

من مركز التحكم في الواجهة ← مكتبة الخلفيات. تصفّح الخلفيات بالريموت، ثم اضغط تطبيق لحفظ اختيارك. توجد الصور الأصلية وخلفيات ثابتة ومتحركة جديدة، ويمكن إضافة صورة أو فيديو محليًا أو من USB. المعاينة وحدها لا تغيّر الخلفية الحالية. يُنصح بفيديو H.264 أفقي 1080p بمعدل 30 إطارًا، وبحد أقصى 60 ثانية و60 ميجابايت. يعمل صامتًا ومتكررًا؛ الفيديو يبقى على التلفزيون.

المستودع الخاص يحمي الوصول إلى ملفات المصدر، لكن ملفات APK قابلة للتحليل؛ لا تتضمن مفاتيح التوقيع أو رموز GitHub السرية.
